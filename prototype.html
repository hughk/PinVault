Help & Guide

Visual Steganography

Hiding secret PINs in plain sight

Pin Vault conceals secret PINs on a randomized matrix of colored numbers. Shoulder-surfers and surveillance cameras see only colorful numeric noise.

The 3 Keys to Your PIN

To read your PIN, combine three elements known only to you:

1
Secret Color

Choose a secret color. The app conceals this color during normal view so onlookers cannot tell which color is genuine.

2
Starting Tile

Remember where your sequence begins on the matrix (e.g. top-left corner, center, or Row 2 Col 3).

3
Traversal Path

Follow your mental path (diagonal, chess knight move, column down, or reverse L-shape).

Tip: Write a subtle Rule Hint that makes sense only to you (e.g., "Knight move from bottom-right").

Anti-Observation Decoys

• Linear Decoy PINs: The algorithm synthesizes decoy lines (horizontal, vertical, or diagonal) across the matrix so viewers see multiple false patterns.

• Strict Non-Adjacency: Decoys sharing your secret color never touch real PIN tiles, eliminating clustering suspicion.

• Concealed Colors: Secret color names are never printed on screen in normal mode.

Emergency Pattern Peeker

If you ever forget your path or need immediate verification:

  1. Tap the "Tap for Biometric Reveal" button.
  2. Authenticate via fingerprint or device PIN.
  3. Secret tokens glow in their authentic color for a 12-second window with a live timer.
  4. Tap again anytime to immediately extinguish the reveal.
Folders & Management

• Filter Chips: Instantly filter by Credit, Debit, Banking, Safes, or custom folders.

• Custom Folders: Tag cards into Personal, Work, Finance, etc.

• Safe Deletion: Permanent deletion with explicit confirmation dialog.

Encrypted Offline Backup

Pin Vault is 100% offline. Export encrypted .pinvault backups with AES-256-GCM (100k PBKDF2 rounds) to transfer devices without cloud exposure.

Heritage & Inspiration

Inspired by an earlier orphaned application "Pin Keeper", which stopped working under newer versions of Android. Re-architected from the ground up for modern Android devices.

Security & Architecture

• 100% Offline: Zero internet permission requested.

• Anti-Snoop: Android FLAG_SECURE blocks screenshots and recordings.

• Strong Cryptography: AES-256-GCM + PBKDF2 for portable backups.

• Biometric Peeker: Android BiometricPrompt hardware integration.
